== The topic in four sentences

The Collection Framework is the `java.util` (and `java.util.concurrent`) vocabulary for groups of objects: List for positions, Set for uniqueness, Queue for a head, Map for key-to-value — and Map is not a Collection. link:overview.adoc[overview.adoc]

You pick the interface for the contract and the class for the cost: ArrayList is a growable array, HashMap is hash-then-equals, TreeMap is comparison, ArrayDeque is a circular array, PriorityQueue is a heap. link:lists.adoc[lists.adoc] link:maps.adoc[maps.adoc] link:queues.adoc[queues.adoc]

Views (`unmodifiableList`, `subList`, `asList`, `reversed`) share storage; `List.of` / `copyOf` snapshot and reject null. link:utilities.adoc[utilities.adoc]

ArrayList and HashMap are one-thread types. Sharing needs a concurrent collection or a lock around every compound use, including iteration. link:concurrent-collections.adoc[concurrent-collections.adoc]

== If you remember only 10 things

. Declare `List`/`Set`/`Map`/`Queue`. Construct the concrete class. link:overview.adoc#collection-hierarchy[overview]
. Map is not a Collection. `keySet`/`values`/`entrySet` are. link:overview.adoc#collection-contract[overview]
. for-each is an iterator. `list.remove` inside it throws `ConcurrentModificationException`; the element may already be gone. link:overview.adoc#fail-fast[overview]
. ArrayList: `get` O(1), insert-in-middle O(n), first add allocates capacity 10, then ~1.5×. link:lists.adoc#arraylist[lists]
. LinkedList is almost never the right List. Queue/stack: `ArrayDeque`. link:lists.adoc[lists] link:queues.adoc[queues]
. HashSet uniqueness is `equals` (via a HashMap). TreeSet uniqueness is the comparator. Keep them consistent. link:sets.adoc#treeset[sets]
. HashMap: table 16, load 0.75, resize at size 13, bins treeify at 8 when table ≥ 64. No Comparable required for that. link:maps.adoc#hashmap-internals[maps]
. `poll`/`offer`/`peek` return special values. `remove`/`add`/`element` throw. PriorityQueue iteration is not sorted. link:queues.adoc#queue-method-families[queues]
. `Collections.unmodifiableList` is a view. `List.copyOf` is a snapshot. `Arrays.asList` is fixed-size. link:utilities.adoc#views-versus-copies[utilities]
. Shared map: `ConcurrentHashMap` (no nulls, per-key atomic). Synchronized wrappers still fail-fast on iteration. link:concurrent-collections.adoc#concurrenthashmap[concurrent]

== Core terms

[cols="1,3"]
|===
|Term |Meaning

|Contract
|The promises a type makes (uniqueness, order, index). link:overview.adoc[overview]

|Capacity vs size
|Array length vs how many elements are in use. link:lists.adoc[lists]

|Fail-fast
|Iterator throws if `modCount` changed. Not a thread-safety tool. link:overview.adoc[overview]

|Weakly consistent
|Concurrent iterator may see some updates, does not throw CME. link:concurrent-collections.adoc[concurrent]

|View
|Second object, same storage. link:utilities.adoc[utilities]

|Load factor
|Resize when `size > capacity × 0.75` (HashMap default). link:maps.adoc[maps]

|Natural order
|The type's `Comparable.compareTo`. link:utilities.adoc[utilities]

|Consistent with equals
|`compare(a,b)==0` iff `a.equals(b)`. Required for TreeSet/TreeMap as a Set/Map. link:sets.adoc[sets]

|Back-pressure
|Bounded blocking queue: `put` waits when full. link:concurrent-collections.adoc[concurrent]

|Sequenced collection
|Has first/last and `reversed()` (Java 21). link:utilities.adoc[utilities]
|===

== Decision table

[cols="2,3"]
|===
|Need |Pick

|Default list
|`ArrayList` (size it if you know n)

|Queue or stack
|`ArrayDeque`

|Next item is smallest
|`PriorityQueue` (single thread)

|Unique, no order
|`HashSet`

|Unique, insertion order
|`LinkedHashSet`

|Unique, sorted / range
|`TreeSet` (comparator consistent with equals)

|Enum flags
|`EnumSet`

|Default map, one thread
|`HashMap`

|Insertion order / LRU
|`LinkedHashMap` (`removeEldestEntry`)

|Sorted map
|`TreeMap`

|Enum keys
|`EnumMap`

|Identity (`==`)
|`IdentityHashMap`

|Shared map
|`ConcurrentHashMap`

|Many readers, rare writes
|`CopyOnWriteArrayList`

|Producer/consumer + wait
|`ArrayBlockingQueue` (set a real capacity)

|Unmodifiable snapshot
|`List.copyOf` / `Set.copyOf` / `Map.copyOf` / `List.of`
|===

== Rules and numbers worth memorizing

* ArrayList default capacity after first add: **10**. Growth: `old + old/2`. link:lists.adoc[lists]
* HashMap default table: **16**. Load factor: **0.75**. First resize at size **13**. link:maps.adoc[maps]
* Treeify: bin size **8** and table length **≥ 64**. Untreeify: **6**. OpenJDK HashMap, not a language rule. link:maps.adoc[maps]
* `List.remove(int)` is index. `List<Integer>.remove(1)` deletes index 1. link:lists.adoc[lists]
* `subList(from,to)`: from inclusive, to exclusive. Structural change on parent invalidates it. link:lists.adoc[lists]
* `List.of` / `Set.of` / `Map.of`: no null. `Set.of` duplicate → `IllegalArgumentException`. link:utilities.adoc[utilities]
* `Map.of` max 10 pairs; then `Map.ofEntries`. link:utilities.adoc[utilities]
* ConcurrentHashMap: no null key or value. link:concurrent-collections.adoc[concurrent]
* ArrayDeque / PriorityQueue: no null. link:queues.adoc[queues]
* Java 19: `HashMap.newHashMap(n)` / `HashSet.newHashSet(n)` size for n elements without an extra resize. link:maps.adoc[maps]
* Java 21: `getFirst` / `getLast` / `reversed`. `reversed` is a view. link:utilities.adoc[utilities]

== Traps

* `HashSet` holds two equal users → `equals` overridden, `hashCode` not. link:../oops/object-class-contracts.adoc[OOP contracts]
* `get` returns null, `size` is 1 → key mutated after `put`. link:maps.adoc[maps]
* `TreeSet` size 2 for `equals` objects → comparator disagrees with equals. link:sets.adoc[sets]
* `ConcurrentModificationException` in for-each → `remove` on the collection, not on the iterator. link:overview.adoc[overview]
* `UnsupportedOperationException` on `add` → `List.of` or `Arrays.asList` or `unmodifiable*`. link:utilities.adoc[utilities]
* `asList.set` changed the array → it is a view. link:lists.adoc[lists]
* `unmodifiableList` grew → original list was still mutated. link:utilities.adoc[utilities]
* `PriorityQueue.toString` looks unsorted → iteration is heap order. link:queues.adoc[queues]
* HashMap size < expected under two threads → not thread-safe. link:concurrent-collections.adoc[concurrent]
* `synchronizedList` for-each throws → must `synchronized (list)` around the loop. link:concurrent-collections.adoc[concurrent]
* `IdentityHashMap.get("x")` misses → keys compared with `==`. link:maps.adoc[maps]
* `Map.copyOf` value list grew → copy is shallow. link:maps.adoc[maps]

List<String> growable = new ArrayList<>(List.of("a", "b"));

list.removeIf(s -> s.equals("b"));          // not list.remove inside for-each
