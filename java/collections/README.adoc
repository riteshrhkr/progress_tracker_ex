== Running the examples

Java 21 or newer. Compile everything once, then run whichever demo you want.

Two demos (`ArrayListDemo`, `HashMapDemo`) read private fields with reflection. They need `--add-opens`. The others run without it.

[source,bash]
----
cd java/collections
javac --release 21 -g -d out $(find examples -name '*.java')

java -cp out examples.overview.HierarchyDemo
java -cp out examples.overview.IteratorDemo
java --add-opens java.base/java.util=ALL-UNNAMED -cp out examples.lists.ArrayListDemo
java -cp out examples.lists.ListTrapsDemo
java -cp out examples.sets.SetContractDemo
java --add-opens java.base/java.util=ALL-UNNAMED -cp out examples.maps.HashMapDemo
java -cp out examples.maps.LinkedHashMapDemo
java -cp out examples.maps.MapPitfallsDemo
java -cp out examples.queues.QueueDequeDemo
java -cp out examples.queues.PriorityQueueDemo
java -cp out examples.utilities.ViewsAndFactoriesDemo
java -cp out examples.utilities.ComparatorDemo
java -cp out examples.concurrent.ConcurrentDemo
----

Each demo has a `main`, prints numbered sections, and needs no arguments or dependencies.

`-g` keeps local variable names in the class files.

`ConcurrentDemo` starts two threads. `HashMap` size after the race is not fixed and is usually below the expected 20000. `ConcurrentHashMap` produced 20000.

All output quoted in the documents was produced by running these files on Temurin 21.0.11 with `--release 21`. Nanosecond timings in `ArrayListDemo` are one run, not a benchmark.

== The shortest possible summary

Pick the interface for the contract (index, uniqueness, lookup, head) and the class for the cost (array, hash table, tree, heap).

`HashMap` / `HashSet` find by hash then equals. `TreeMap` / `TreeSet` find by comparison. Iteration order is a promise only when the type says so (`List`, `LinkedHash*`, `Sorted*`).

Do not share `ArrayList` or `HashMap` across threads. Fail-fast iterators detect structural change on one thread; they are not a concurrency story.
