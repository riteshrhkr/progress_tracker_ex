== The topic in four sentences

OOP keeps data and the operations allowed on that data in one place, so the rules about valid data have exactly one home.

A class is the description, an object is the block of heap memory, and your variable only ever holds the address.

Methods are chosen at runtime from the real object; fields, static methods and overloads are chosen at compile time from the declared type.

Most real-world OOP mistakes are one of three things: a leaked mutable reference, an inheritance relationship that should have been composition, or `equals` without a matching `hashCode`.

== If you remember only 10 things

. A variable holds a reference, never an object. `==` compares addresses.
. Arguments are always copied. A method can mutate your object, never repoint your variable.
. Overriding is decided by the object at runtime; overloading by the declared type at compile time.
. Fields and `static` methods are *hidden*, not overridden — the declared type wins.
. Never call an overridable method from a constructor: the subclass version runs against uninitialized fields.
. `private` protects the reference, not the object it points at. Return a copy.
. `final` stops reassignment of a variable. It does not make the object immutable.
. Override `equals` and `hashCode` together, from immutable fields only.
. Extending a class couples you to its self-use, which is undocumented and can change.
. Make nested classes `static` unless they truly need the outer instance.

== Core terms

[cols="1,3"]
|===
|Term |One-line meaning

|Reference
|The address of an object; what every non-primitive variable holds.

|Invariant
|A rule that must be true about an object at all times, such as "balance is never negative".

|Dynamic dispatch
|Picking the method at runtime from the object's real class.

|Hiding
|A subclass field or static method with the same name as the parent's; both exist, the declared type picks.

|Covariant return
|An override returning a subtype of the declared return type.

|Self-use
|One method of a class calling another overridable method of the same class.

|Coupling
|How much one piece of code depends on another's internals.

|Cohesion
|How closely the things inside one class belong together.

|Compact constructor
|A record constructor with no parameter list, used to validate or replace the incoming values.

|Effectively final
|A local variable assigned once and never reassigned; required for capture by a lambda or local class.

|Template method
|A `final` method fixing the algorithm and calling `protected abstract` steps that subclasses fill in.
|===

== Rules and numbers worth memorizing

* Init order per object: parent field initializers and instance blocks → parent constructor → child field initializers and instance blocks → child constructor. link:oop-fundamentals.adoc[fundamentals]
* Static blocks run once, at first use of the class, parent before child.
* Field defaults: `0`, `0.0`, `false`, `'\u0000'`, `null`. Locals have no default; the compiler rejects reading them.
* Override may *widen* access, *narrow* the return type and *narrow or drop* checked exceptions. Never the reverse.
* `final`, `static` and `private` methods cannot be overridden.
* Overload matching order: widening → boxing → varargs. First match wins.
* Access: `private` < package-private < `protected` < `public`. `protected` includes package access.
* `Integer` cache is -128..127, so `==` on boxed values works below 128 and then stops.
* HotSpot object header: ~12 bytes with compressed pointers, padded to 8; an object with one `int` is 16 bytes. Implementation detail, not a language rule.
* Versions: default methods 8, private interface methods 9, `List.copyOf` 10, helpful NPE messages 15, `instanceof` pattern 16, records 16, `sealed` 17, pattern matching for `switch` final in 21.

== Traps

Symptom first, then cause.

* `HashSet` holds two objects you consider equal → `equals` overridden, `hashCode` not. link:object-class-contracts.adoc[contracts]
* `map.get(key)` returns `null` but `map.toString()` shows the entry → a key field was mutated after `put`.
* A `final` field is `null` inside a method → an overridable method was called from the constructor. link:oop-fundamentals.adoc[fundamentals]
* The `Animal` variable prints the `Animal` name but the `Dog` sound → fields hide, methods override. link:four-pillars.adoc[pillars]
* Overload picks `pick(Object)` for a `String` → the variable is declared `Object`; overloads resolve at compile time.
* `pick(null)` will not compile → two equally specific overloads; cast the `null`.
* Counter reports 6 after adding 3 → `addAll` in the parent calls the overridden `add`. link:design-principles.adoc[design]
* An "immutable" object changed → the constructor stored the caller's collection, or the getter handed the internal one back. link:object-class-contracts.adoc[contracts]
* `UnsupportedOperationException` from an implementation → the interface is too fat, split it. link:design-principles.adoc[design]
* Heap grows slowly and nothing looks retained → an inner class instance is keeping its outer object alive. link:design-principles.adoc[design]
* `x == y` true for 127 and false for 128 → boxed `Integer` cache. link:oop-fundamentals.adoc[fundamentals]
* Square resized to 5x4 has area 16 → a subtype broke a promise the parent made. link:design-principles.adoc[design]

== Code I should be able to write from memory

`equals` and `hashCode`:

[source,java]
----
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof GoodUser other)) return false;
    return email.equals(other.email);
}
@Override public int hashCode() { return Objects.hash(email); }
----

A guarded constructor plus defensive copies:

[source,java]
----
SafeTrip(String name, List<String> stops) {
    if (name == null || name.isBlank()) throw new IllegalArgumentException("name required");
    this.name = name;
    this.stops = List.copyOf(stops);
}
List<String> stops() { return stops; }
----

Composition instead of extension:

[source,java]
----
final class CountingSet<E> {
    private final Set<E> delegate = new HashSet<>();
    private int added;
    boolean add(E e) { added++; return delegate.add(e); }
}
----

Template method:

[source,java]
----
abstract class Report {
    final String render() { return "[" + title + "]\n" + body(); }
    protected abstract String body();
}
----

Sealed type plus exhaustive switch:

[source,java]
----
sealed interface Payment permits Card, Cash {}
String describe(Payment p) {
    return switch (p) {
        case Card c -> "card " + c.last4();
        case Cash ignored -> "cash";
    };
}
----
