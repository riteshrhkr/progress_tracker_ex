== Quick distinction

[cols="1,3"]
|===
|Term |Plain meaning

|JVM
|The program that loads bytecode, manages memory, and runs your methods (interpreter + JIT).

|JRE
|JVM plus the standard libraries you need to *run* a Java app.

|JDK
|JRE plus tools to *build* an app (`javac`, `javap`, `jcmd`).

|JMM
|The *rules* for when one thread's write becomes visible to another thread. It is a spec, not a box inside the JVM diagram.
|===
